### Findings

**F1 — blocker — Worker instructions and parser disagree**  
`coordinator/loop.py:204`, `coordinator/runtime.py:252`

Both agent instructions require fenced JSON addressed to the coordinator. Switch’s targeted-message operation prepends mentions and preserves the body. A compliant Supervisor reply therefore fails parsing, retries once, then fails without requesting the AD.

**Fix:** implement one bounded, documented mention/fence envelope extractor before Pydantic validation. Reject ambiguous blocks or trailing substantive text; preserve identity, job and revision checks.

**F2 — blocker — Renderer inputs are incompatible and can inherit fictional defaults**  
`coordinator/dispatcher.py:142`, `:199`; `coordinator/render_bridge.py:32`; `render/src/schema.ts:5`, `:21`

Preview dispatch supplies only a scheduling manifest; call-sheet dispatch supplies `{scenes: [...]}`. Required presentation fields are missing.

| Output | Mismatches |
|---|---|
| Preview metadata | Missing `letter`, `label`, `scene_number`, `scene_title`. |
| Preview identity | Required `manifest_hash` is absent and explicitly stripped by the bridge. |
| Preview people | Supplies `string[]`; renderer expects `{id, name}[]`. |
| Preview limits | Coordinator permits 100 shots/200 people; renderer permits 6/4. Location, shot and label lengths also differ. |
| Preview overrides | No coordinator representation for optional `sunset`/`crowd`. |
| Call-sheet production | Missing `production {title, day, date, timezone}`. |

| Call-sheet top level | Missing `general_call`, `crew`, `locations`, `confirm_hint`; optional sunset absent. |
| Call-sheet scenes | Missing number/title/cast; people IDs are not cast rows. Held rows lack executable location/times and have no renderer representation. `unchanged` is not `changed`. |
| Call-sheet limits | Coordinator permits 200 scenes/500 crew/200 locations; renderer permits 12/20/6. |
| Input size | Python accepts 256 KiB; CLI accepts 64 KiB. |

**Correction to Claude C1:** schema registration does not itself parse CLI props. Installed Remotion source merges default props with supplied inputs. Previews can consequently inherit **A / Stairwell, reduced coverage**, default scene metadata and a sample hash while being marked ready. Call-sheet rows lack `cast`, causing `s.cast.join` at `render/src/CallSheet.tsx:63` to fail.

**Fix:** construct and validate explicit preview/call-sheet props from immutable manifests and trusted metadata. Separate manifest hashing from presentation props, include the real hash, support held rows, and align limits.

**F3 — blocker — Publication resumes before replay reconciles missed changes**  
`coordinator/runtime.py:164`, `:175`, `:177`, `:198`; `coordinator/switch_client.py:351`

**F8 — major — Timely answers are lost when processed after expiry**

**F10 — major — Switch acceptance is shown as Discord publication**

**F17 — major — Boundary mismatches bypass worker retry handling**  
`coordinator/runtime.py:61`, `:228`; `coordinator/constraints.py:127`; `coordinator/ui_models.py:95`, `:101`

**Fix:** share compatible limits across transport, checker, State and renderer. Validate projection compatibility before completing jobs; route attributable failures through the bounded worker retry path.

**F18 — minor — Replacement questions and caches have no lifecycle bound**

**Fix:** cap replacements within the original deadline, store immutable payloads once in SQLite, and archive active references without losing history/dedupe.
